# 🧠 Hybrid Statistical and ML Framework for Early Prediction of Alzheimer's Disease

A hybrid statistical and machine learning framework for the early prediction of Alzheimer's disease using clinical data. This project combines exploratory statistical analysis with multiple machine learning models to identify individuals at risk and support early diagnosis.


## 📌 Overview

Early diagnosis of Alzheimer's disease is essential for timely medical intervention and improved patient care. This project analyzes clinical data, performs statistical analysis, and evaluates multiple machine learning algorithms to develop an accurate prediction framework.


## 🎯 Objectives

- Analyze clinical data related to Alzheimer's disease.
- Perform data preprocessing and exploratory data analysis.
- Build and compare multiple machine learning models.
- Evaluate model performance using standard classification metrics.
- Identify the best-performing model for early disease prediction.


## 📂 Dataset

- Clinical Alzheimer's Disease Dataset
- **Records:** 2,149
- **Features:** 33
- **Target Variable:** Diagnosis (Alzheimer's Disease)


## 🛠️ Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook


## 🔬 Methodology

### Data Preprocessing

- Removed unnecessary features
- Checked for missing values
- Encoded categorical variables
- Performed feature scaling
- Split data into Train (70%), Validation (15%), and Test (15%)


### Exploratory Data Analysis

- Feature distribution analysis
- Correlation analysis
- Target class distribution
- Statistical summary
- Data visualization


### Machine Learning Models

- Decision Tree
- Random Forest
- Gradient Boosting
- Logistic Regression
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Bernoulli Naïve Bayes


## 📊 Model Evaluation

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC Score
- Confusion Matrix


## 🏆 Results

| Model | Best Performance |
|--------|------------------|
| Decision Tree | **94.74% Accuracy** |
| Gradient Boosting | **ROC-AUC: 0.9645** |

The Decision Tree model achieved the highest classification accuracy, while Gradient Boosting demonstrated the strongest discrimination capability based on ROC-AUC.
